# UAT - kit v4.3, token cost is a design input - 2026-08-27

**Branch:** prelive   **Environment:** local (this is a developer tool, not a deployed app)   **Prepared by:** Claude Code   **Status:** awaiting sign-off

## What changed

The kit now has an opinion about what it costs to run. Every agent it ships declares which model it runs on, instead of silently inheriting whatever the session is using — so a formatting job no longer runs on the same model as a correctness review. The two heavyweight reviewers are told to read the diff rather than the repository. And there is a new command, `refresh`, for taking a new kit release into an existing repo: it updates the agents, commands, hooks and CI gates, and deliberately touches nothing else — not your CI workflow, not your environment file, not your branches.

Fixing the model routing surfaced a silent bug: `design-reviewer` was excluded from the refresh path, so no kit-wide change to its frontmatter had reached an existing repo since that exclusion was written. It now ships like every other agent. Your own `.claude/rules/design.md` is still yours and is never overwritten.

## Preconditions

- A machine with the kit installed (`python ~/.claude/sonelo/repo_setup.py --version` reports 4.3 after updating).
- At least one repo already set up with kit v4.1 or v4.2, ideally one with a local edit in `.githooks/checks` and hand-written text in `CLAUDE.md` outside the `sonelo-devkit` markers.
- A second, throwaway repo for the destructive cases.

## Test data

Use a scratch repo for cases 1-7:

```
mkdir r && cd r && git init -b main
echo '{"name":"r"}' > package.json && git add -A && git commit -m "chore: init"
python ~/.claude/sonelo/repo_setup.py apply
git add -A && git commit -m "chore: apply sonelo repo standards"
```

Then make it look like an older repo before refreshing:

```
sed -i '/^model: sonnet$/d' .claude/agents/design-reviewer.md
echo '# my own check' >> .githooks/checks
echo '# house policy' >> CLAUDE.md
```

## Not covered here

- **The saving itself is not proven by this PR.** The measurement that motivated it (74% of 28-day spend being context re-reads) was taken before the change; whether the model routing and reading budget actually reduce it can only be seen in the worklog over the following weeks. UAT-14 establishes the baseline, not the result.
- **The two machine-level changes are not in this diff** and cannot be tested from the repo: `~/.claude/settings.json` model default (`opus[1m]` → `opus`) and `~/.claude/worklog.json` prices. They apply to this machine only and travel to other machines by hand.
- Bundle-size budgets, and the per-session context high-water mark in the worklog, are deferred to v4.4 (ADR-0004 records why).
- No database, auth, or edge-function surface exists in this repo, so there is nothing to verify there.
